# ni225simple

[日経平均先物 CME・SGX リアルタイムチャート（nikkei225jp.com/cme/）](https://nikkei225jp.com/cme/)
の表示を、ツールバーから 3 通りに切り替える Firefox 拡張機能。

| モード | 見えるもの |
| --- | --- |
| 複合チャートのみ | ページ上部の「複合チャート」の枠だけ。メニュー・表・サイドバー・広告は隠す |
| 複合チャート以外 | 複合チャートの枠だけを隠し、ほかはそのまま |
| すべて | 元のページのまま |

---

## できること

**タブごとに別のモードにできる**
タブ A は「複合チャートのみ」、タブ B は「すべて」のように、タブごとに選べます。
ほかのタブには影響しません。

**次に起動したときもそのまま**
Firefox がタブを復元すると、そのタブのモードも一緒に戻ります。
（Firefox の設定「前回のウィンドウとタブを開く」が有効なとき）

**今のモードがアイコンで分かる**
ツールバーのアイコンに、「複合チャートのみ」なら **図**、「複合チャート以外」なら
**他** と表示されます。「すべて」のときは何も付きません。

**権限は最小限**
インストール時の確認に出る権限は「nikkei225jp.com ドメイン下のサイトデータへの
アクセス」の 1 つだけです。これは対象ページの表示を切り替えるのに必要な分で、
実際に動くのは `https://nikkei225jp.com/cme/` のページの中だけです。
タブや履歴を読む権限、保存領域の権限は使っていません。
外部との通信も、データの収集もしません。

## インストール

1. [Releases](../../releases) から最新の `.xpi` を開く
2. Firefox が「追加しますか」と訊いてくるので「追加」

Mozilla の署名済み（非公開配布）なので、通常版の Firefox にそのまま入ります。
Firefox 142 以降が必要です。

## 使い方

1. `https://nikkei225jp.com/cme/` を開く
2. ツールバーのアイコンを押し、モードを選ぶ

選んだ瞬間にそのタブの表示が切り替わります。再読み込みは要りません。
対象外のページでアイコンを押すと、「このページでは使えません」と表示されます。
