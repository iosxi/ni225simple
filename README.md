# ni225simple

[日経平均先物 CME・SGX リアルタイムチャート（nikkei225jp.com/cme/）](https://nikkei225jp.com/cme/)
の表示を、ツールバーから 3 通りに切り替える Firefox 拡張機能。

| モード | 見えるもの |
| --- | --- |
| 複合チャートのみ | ページ上部の「複合チャート」の枠だけ。メニュー・表・サイドバー・広告は隠す |
| 複合チャート以外 | 複合チャートの枠だけを隠し、ほかはそのまま |
| すべて | 元のページのまま |

その下のチェックボックスで、ページの部品を個別に隠せます（モードと組み合わせ可）。

| チェックボックス | 効果 |
| --- | --- |
| サイドバーを非表示 | 右のサイドバーを隠し、空いた幅に合わせて本文を 1.42 倍に拡大 |
| 赤枠を非表示 | 上部の赤枠のお知らせを隠す |
| トップメニューを非表示 | 上部のタイル状のメニューを隠す |
| リンクメニューを非表示 | アクセスランキングと各ページへのリンク集を隠す |
| ヘッダーを非表示 | 見出し・株価帯・時計・トップメニューなど、ページ上部をまとめて隠す |

---

## できること

**タブごとに別の設定にできる**
タブ A は「複合チャートのみ」、タブ B は「すべて」＋サイドバー非表示のように、
タブごとに選べます。ほかのタブには影響しません。

**次に起動したときもそのまま**
Firefox がタブを復元すると、そのタブの設定も一緒に戻ります。
（Firefox の設定「前回のウィンドウとタブを開く」が有効なとき）

**ブックマークから設定どおりに開ける**
設定はアドレスバーの URL にも反映されます（例: `https://nikkei225jp.com/cme/?mode=chart&nosidebar=1`）。
その画面をブックマークしておけば、次からはそこを開くだけで同じ設定になります。
URL の書きかたは下の「URL で設定を指定する」を参照。

**今のモードがアイコンで分かる**
ツールバーのアイコンに、「複合チャートのみ」なら **図**、「複合チャート以外」なら
**他** と表示されます。「すべて」のときは何も付きません。

**権限は最小限**
インストール時の確認に出る権限は次の 2 つだけです。

- 「nikkei225jp.com ドメイン下のサイトデータへのアクセス」— 対象ページの表示を
  切り替えるため。実際に動くのは `https://nikkei225jp.com/cme/` のページの中だけです。
- 「最近閉じたタブへのアクセス」— 設定をタブに結び付けて、再起動後の復元でも
  戻すため（Firefox の `sessions` 権限）。閉じたタブの一覧を読むことはしません。

タブの URL やタイトルを読む権限、履歴の権限は使っていません。
外部との通信も、データの収集もしません。

## インストール

1. [Releases](../../releases) から最新の `.xpi` を開く
2. Firefox が「追加しますか」と訊いてくるので「追加」

Mozilla の署名済み（非公開配布）なので、通常版の Firefox にそのまま入ります。
Firefox 142 以降が必要です。

## 使い方

1. `https://nikkei225jp.com/cme/` を開く
2. ツールバーのアイコンを押し、モードを選ぶ

選んだ瞬間にそのタブの表示が切り替わります。再読み込みは要りません。
対象外のページでアイコンを押すと、「このページでは使えません」と表示されます。

## URL で設定を指定する

`https://nikkei225jp.com/cme/` の後ろに、次のパラメータを付けて開くと、その設定で表示されます。
設定はそのタブに記憶されるので、以後はポップアップから変えられます。

| パラメータ | 値 | 意味 |
| --- | --- | --- |
| `mode` | `chart` / `other` / `all` | 複合チャートのみ / 複合チャート以外 / すべて |
| `nosidebar` | `1` / `0` | サイドバーを非表示 |
| `noakawaku` | `1` / `0` | 赤枠を非表示 |
| `notopmenu` | `1` / `0` | トップメニューを非表示 |
| `nolinkmenu` | `1` / `0` | リンクメニューを非表示 |
| `noheader` | `1` / `0` | ヘッダーを非表示 |

書かなかった項目は既定値（`mode=all`、チェックボックスは OFF）になります。例:

- `https://nikkei225jp.com/cme/?mode=chart` — 複合チャートだけ
- `https://nikkei225jp.com/cme/?mode=other&nosidebar=1&noheader=1` — 複合チャート以外、サイドバーとヘッダーなし

ポップアップで設定を変えると URL も書き換わります（履歴は増えません）。
すべて既定値に戻すと、パラメータは消えます。

ページのタイトルの末尾にも設定が付くので、ブックマークやタブで見分けられます。例:
`?mode=other&notopmenu=1&noheader=1` →「225先物 CME SGX 大取 夜間 リアルタイム チャート mode=other notopmenu noheader」
